# EVERDUSK — playable build

Light the city. Outrun the Hush. A painted 2D night-market runner.

**Play: https://junhee0128.github.io/everdusk-play/**

Phones play in landscape and can be added to the home screen.
Tap to jump, swipe down to slide, swipe right to dash — a dash breaks the
Hush bodies that have a glowing core; the ones without a core are only to
be avoided. Green Sparks are collected.

This repository holds only the built output. The source is private.
